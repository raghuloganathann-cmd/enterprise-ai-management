# Enterprise AI Management

A simple base project for managing an organisation's AI models, spend and use-case approvals.

## Features
- Overview: model counts, weekly spend, daily spend chart, budget tracker
- Models: registry to add, pause, resume and remove AI models
- Governance: submit AI use-case requests and approve or reject them

## Run
No installation needed. Open `index.html` in any browser.

## Files
- index.html - page structure
- style.css  - styling (light and dark mode)
- app.js     - data, views and event handling (saved in browser localStorage)
